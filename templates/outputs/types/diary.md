# 日记类型

每篇产出对应一个 Key Line（一天的实践），以叙事方式还原当天的实践过程。

## 结构蓝图

- 标题：抓住当天最关键的事
- 元信息行：Day N / 日期 / KL 骨架链接
- 正文段落：2-3 件事的叙事展开
- 收获总结：3-5 条精炼认知
- 底部：相关 Groups 链接

## 质量标准

- 素材忠实度：所有事实必须来自 journal 原始素材
- 叙事连贯性：段落之间有自然的承接
- 详略得当：重点事件展开，次要事件一笔带过
- 链接正确性：所有引用路径必须有效
