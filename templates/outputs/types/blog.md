# 博客类型

将整个视角凝练为一篇完整的博客文章，面向技术社区读者。

## 结构蓝图

- YAML frontmatter：title, date, tags, description
- 引言：由 SCQA 驱动，引出核心主张
- 正文章节：每个 Key Line 对应一个章节，结论先行
- 结论与行动号召：总结核心观点，引导读者下一步

## 质量标准

- 独立可读：不依赖知识库内部结构即可理解
- 观点明确：每个章节有清晰的论点
- 证据充分：论点有来自 groups/atoms 的支撑
- 结构完整：引言-正文-结论三段式
